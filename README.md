## Hi, I'm z23

Random bits of network / infrastructure tooling, terminal apps, and desktop tinkering. I have no idea what I'm doing.

### Network / infrastructure

- [xenadmin-rs](https://github.com/z23/xenadmin-rs) — standalone Linux XCP-ng management client with a Rune UI and Rust backend, connecting directly to XAPI.
- [pdns-acme-proxy](https://github.com/z23/pdns-acme-proxy) — scoped per-app API keys for PowerDNS, so ACME clients can share DNS-01 without god-mode credentials.
- [netbox-mcp-server](https://github.com/z23/netbox-mcp-server) — NetBox MCP server with opt-in write tools; read-only by default.
- [hyperglass](https://github.com/z23/hyperglass) — hardened looking-glass fork with query validation, shared Redis rate limits, and RCE fixes.
- [GlobalProtect-openconnect](https://github.com/z23/GlobalProtect-openconnect) — fork with gpwidget for Waybar / DankMaterialShell, plus EL10 packaging.

### Kindroid

- [kindroid-gui](https://github.com/z23/kindroid-gui) — native Kindroid window that shares chats with kindroid-tui.
- [omarchy-plugin-kindroid](https://github.com/z23/omarchy-plugin-kindroid) — chat with your Kindroids from the Omarchy bar, powered by kindroid-tui.
- [hermes-kindroid](https://github.com/z23/hermes-kindroid) — connect Hermes Agent to an existing Kindroid companion as a separate participant, with explicit messages and attributed replies.
